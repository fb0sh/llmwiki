# LLM Wiki

欢迎。这是一个由 LLM 持续维护的个人知识库。

## 原则

- **知识被编译一次，持续更新** — 而不是每次查询重新推导
- **LLM 写，人类读** — LLM 负责书摘、交叉引用、维护；人类负责策展和提问

## 如何开始

1. 把源文档放入 `raw/`
2. 对 pi 说「处理这个新源」
3. LLM 会写摘要、建概念/实体页、维护索引

## 结构

- `raw/` — 原始文档（不可变）
- `wiki/concepts/` — 概念页
- `wiki/entities/` — 实体页
- `wiki/sources/` — 源摘要
- `wiki/qa/` — 归档查询

详见 `../index.md` 获取最新内容列表。
